# Project context — Bragi Taste Agent

## Vision

**Bragi Taste Agent — Discover local creativity through your cultural DNA.**

An AI-powered cultural discovery platform that connects people with independent artists, creative services, and local cultural experiences using Qloo Taste Intelligence.

## Problem

Independent artists in cities like Medellín lack culturally intelligent discovery channels. Generic LLM recommenders invent affinities; popular lists ignore niche taste. Artists remain invisible; seekers get noise.

## Solution

Users provide cultural signals (musicians, films, genres, brands, places). Bragi:

1. Resolves those signals to Qloo entities.
2. Queries Qloo Insights for cross-domain affinities.
3. Matches affinities against a curated Medellín catalogue.
4. Returns ranked recommendations with evidence-based explanations.

## Differentiator

| Not this | This |
| --- | --- |
| Generic chatbot | Multi-step tool-using discovery agent |
| Popularity lists | Qloo affinity-grounded ranking |
| Fabricated explanations | Provenance tied to Qloo entities/tags |
| Blockchain marketplace (legacy Bragi) | Taste-intelligence discovery MVP |

## Audience

- Visitors and residents seeking cultural experiences in Medellín.
- Independent artists and creative spaces seeking culturally matched audiences.

## Legacy Bragi

Original product: ICP-based artist–customer marketplace (canisters + Vite frontend). Product vision evolves to taste intelligence; ICP stack remains in-repo but is **out of scope** for the hackathon MVP unless a concrete requirement appears.
